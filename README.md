# BMI Calculator

A simple command-line Python script that calculates Body Mass Index (BMI) based on user's input (weight and height) and displays the corresponding weight category.

## Requirements
* Python 3.x
* No external libraries required.

## How to Run

1. Download the `bmi.py` file.
2. Open your terminal or command prompt in the file's directory.
3. Run the script using the following command:

```bash
python bmi.py
```
